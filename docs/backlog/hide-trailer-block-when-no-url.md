# блок трейлера рендерится даже когда trailerUrl отсутствует

На `/movie/:id` блок трейлера (заголовок секции + декоративный градиент с play-кнопкой) рендерится
безусловно в обоих респонсив-вариантах: `MediaTab.tsx:17-39` (desktop, вкладка Media) и
`MovieMobile.tsx:327-351` (`MobileMedia`). Когда `m.trailerUrl` пуст, кнопка просто становится
`disabled` вместо того, чтобы скрыть секцию целиком — то есть пользователь видит декоративную плашку
"Trailer" без какого-либо контента за ней. Секцию нужно не рендерить вовсе, если `trailerUrl`
отсутствует, — в обоих файлах одинаково.
