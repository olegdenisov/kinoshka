# трейлер нельзя воспроизвести — play-кнопка просто открывает ссылку в новой вкладке

На `/movie/:id` кнопка play в блоке трейлера — это `<a href={m.trailerUrl} target='_blank'>`
(`MediaTab.tsx:26-33`, desktop; тот же паттерн в `MovieMobile.tsx:334-341`, `MobileMedia`), то есть
клик просто уводит на внешний ресурс вместо воспроизведения видео внутри приложения. Нужно добавить
реальное воспроизведение трейлера (инлайн-плеер/модалка) вместо перехода по ссылке — дизайн решения
(embed vs модалка, поддержка разных источников `trailerUrl`) пока не проработан.
